# Loop Studio

Loop Studio is a modern React dashboard for pricing AI automation packages for local businesses. It turns the "sell loops, not vague AI agents" idea into a usable pricing workspace: pick a business type, select automation loops, tune labor/value assumptions, and preview a proposal with setup and monthly retainer numbers.

## Features

- Business-specific loop presets for dental clinics, med-spas, contractors, and accounting firms.
- Selectable loop cards for Review Response, No-Show Recovery, Quote & Estimate, Bookkeeping, and Content Repurposing.
- Live value-replaced calculation based on software cost, labor hours, loaded hourly rate, and retainer share.
- Proposal preview with recommended retainer, setup fee, savings, confidence meters, routing plan, and privacy-box toggle.
- Responsive modern SaaS UI with desktop and mobile layouts.

## Tech Stack

- React
- Vite
- Lucide React icons
- Plain CSS design system

## Why This Exists

Small businesses do not usually buy "AI agents." They buy concrete outcomes: fewer missed appointments, faster quotes, review replies, cleaner books, and more content from the work they already created. Loop Studio helps an automation consultant package those outcomes into a proposal with numbers attached.
